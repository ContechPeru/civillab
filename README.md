# CivilLab UNSAAC v1.0.0

Suite computacional de laboratorio para **Tecnología de Materiales (IC151)** y **Tecnología del Concreto (IC152)**, Facultad de Ingeniería Civil, Universidad Nacional de San Antonio Abad del Cusco (UNSAAC).

**▶ Usar en el navegador, sin instalar nada:** https://inkaia.tech/civillab/

## Qué hace

Procesa los ensayos de laboratorio, contrasta los resultados con los límites normativos (NTP, ASTM, ACI PRC-211.1-22, RNE E.060, E.070 y E.010), genera los gráficos y emite las fichas de resultados en Excel. Incluye 24 cuadernos interactivos:

- **Tecnología de Materiales:** TM-01 a TM-12
- **Tecnología del Concreto:** TC-01 a TC-11
- **Diseño de mezclas:** DM-01 (ACI 211.1)

## Cómo usarlo

1. Abre https://inkaia.tech/civillab/
2. Entra a la carpeta de tu curso y abre la práctica.
3. Elige **Run → Run All Cells**. La primera vez tarda entre 30 y 60 segundos.
